# 失败案例与诊断路径

| 症状 | 观察和定位 | 可复用规则 | 验证边界 |
|---|---|---|---|
| PYNQ 2.4 DMA 实例化中断报错 | 原 HWH 未形成可用控制器；加入 AXI INTC 后通过 | 先查元数据和实际 IRQ 拓扑 | 不是所有 PYNQ 都要求相同拓扑 |
| VDMA 能提交帧但屏幕无信号 | 旧解包器未将 3 个 32-bit 字转为 4 个 BGR888 像素 | 用像素字节、行长、TLAST/SOF 测试 | DMA 完成不是屏幕输出证明 |
| 颜色写入读回不符 | component/驱动说明和打包 HDL 陈旧不一致 | 干净综合并核对实际寄存器 HDL | 不要只看软件头文件 |
| 中文正常，字母数字为方框 | Droid fallback 无完整拉丁字形 | 显式选择中文和拉丁字体 | 不能依赖 Pillow 自动回退 |
| 临时校色正确、重启后偏色 | 原 RBG 补偿重启后不适用；BGR 恢复 | 明确像素格式、矩阵，做可重复启动实验 | 尚不能据此断言唯一硬件根因 |
| 鼠标被页面绘制拖慢 | 整帧缩放和文字绘制耗时长 | 缓存、后台绘制、输入独立处理 | 空闲 CPU 降低不代表回放 FPS 提高 |

每次排查保留：输入条件、版本哈希、原始报错、寄存器读回、尝试、结果和仍不确定的部分。
