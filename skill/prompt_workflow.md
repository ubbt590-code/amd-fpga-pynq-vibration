# 可复用提示工作流

这些提示由本项目调试经验整理；尚未在陌生题目上做成功率实验。

## 软硬件划分

输入采样率、帧长、通道数、更新周期、器件资源和精度要求，请列出 PS 与 PL 的任务分工、流式数据格式、控制寄存器、缓存、最坏情况时延与可验证测试。区分真正的通道并行与单链路时分复用。未测出的指标标为待测。

## 仿真与黄金参考

依据给定 RTL/HLS 源码和接口契约，请提出零、脉冲、整 bin 正弦、边界幅值、随机帧和回压测试；为每一项列出黄金参考、定点截位及饱和约定、TLAST/SOF 期望值和失败标准。不得以软件参考的运行结果替代 PL 实测。

## 性能审查

依据逐帧时间戳和原始测量结果，请区分采样收集、DMA/驱动、算法、分类、渲染和屏幕更新时间。报告中位数、尾部时延、长时间吞吐和丢帧；说明具体更新周期是否可满足，不能由短时均值推出硬实时保证。

## 纠错记录

对每个修改填写现象、旧解释、反证、新解释、代码版本、测试和未解决项。只记录实际出现的提示、回答与工具结果，不编写虚构对话。
