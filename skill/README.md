# PYNQ 工程验证技能包

这是 AMD 自主选题工程交付中的 skill/ 目录，不是个人环境里的插件，也不需要联网安装。

## 适用范围

适用于具有 bit/hwh、AXI-Lite 寄存器、AXI DMA 或 AXI VDMA 的 PYNQ 工程。流程不依赖振动分类器。AX7020 / PYNQ 2.4 是本队实际验证平台；其他板卡和 PYNQ 版本属于待验证范围，不能声称已经跨板验证。

## 使用方式

1. 按 `overlay_workflow.md` 检查元数据、驱动、传输和视频格式。
2. 用 `golden_compare.py reference.npy actual.npy --atol 0.001 --rtol 0.01` 比较硬件结果与黄金参考。明确误差阈值来自哪个量化步骤，不要为使测试通过随意放宽。
3. 按 `debug_cases.md` 从症状、寄存器读回、最小测试到结论形成证据链。
4. 使用 `prompt_workflow.md` 为另一题目执行相同的工程审查。提示词是本次经验提炼，尚未验证其跨题目成功率。

## 验证状态和失效条件

- 比对脚本用受控相同数组、受控误差数组、非有限数和形状不一致进行自检；结果见 `validation.json`。它证明数值比较器工作，不证明任何一套 FPGA 算法正确。
- AX7020 上真实完成过 bit/hwh 加载、FIR 系数读回、512-bin DMA 结果、五类诊断和视频三原色比对；历史记录见工程 evidence/。
- HDL 与寄存器说明不一致、重新下载 Overlay 后其他进程仍使用旧对象、缓存未同步、TLAST/SOF 不符契约时，必须先修接口，不能靠结果缩放补偿。
- 显示三原色正确不等于证明冷启动可重复；软件寄存器读回不等于测到了 HDMI 引脚信号。
- 本技能包尚未完成第二块板卡或陌生队伍的独立复现，不将通用性设计等同于已验证迁移。

本目录从本队的 DMA 中断映射、陈旧视频 IP、缺字、颜色补偿和误判初始化原因等实际失败中提炼。具体原始对话仍需连同协作记录导出。
